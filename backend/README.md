# Government Scheme Retrieval System

## Overview
Government Scheme Retrieval System is a Python-based search system that helps users find relevant government schemes based on their requirements.

Instead of searching by exact scheme names, users can enter normal queries like "scholarship for students" or "financial support for farmers", and the system retrieves matching schemes.

## Features
- Search government schemes using user queries
- Retrieves top matching schemes
- Displays scheme details, benefits, and eligibility
- Shows similarity score for retrieved results
- Highlights matching keywords in the output
## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP techniques
- TF-IDF Vectorization
- Cosine Similarity
